# Problem-Solving

A collection of my solutions to programming problems, gathered as I practice and sharpen my problem-solving skills over time.

## About

This repository serves as my personal archive of solved problems — covering topics like data structures, algorithms, math, and general logic building. It's organized by category and difficulty so I (and anyone else browsing) can easily track progress and revisit past solutions.

## Structure

Solutions are organized into folders by category, with each problem typically containing:
- The source code for the solution
- A brief note on the approach, when needed

```
Problem-Solving/
├── Category-1/
│   ├── Difficulty-1/
│   └── Difficulty-2/
├── Category-2/
│   └── ...
└── README.md
└── .gitignore
```

## Purpose

- Track and document my problem-solving journey
- Build a personal reference for revisiting patterns and techniques
- Stay consistent with regular practice
